In most courses or learning projects, we utilize explicit feedback. This is direct information of what each user likes and dislikes, for example movie ratings. However, in many different fields this won't be the case. A common example of this is user clicks on an online shop. We can think of users clicking on a product meaning they are interested in it. One might think that a user not clicking on something means they dislike it, whereas in reality the user might have been interested in it but simply did not see it.
