We now have vector representations of the documents, how can we utilize them for say search engines? In these cases it is useful to look at how similar the vectors might be. For instance, we can use similar vectors to find research papers in a given field. In this section, we will discuss some methods on computing a similarity.
# Euclidean Distance
In machine learning, we typically assume that vectors live in a Euclidean space, where vector components are just the length of the vector in one of the basis vectors. Thus we can utilize the distance between vectors as a measure of similarity. Vectors that are close to each other are more similar and those farther away are more dissimilar. So some negative function of the distance.
# Cosine Similarity
Another way of scoring vector similarity is by using the angle between two vectors. Recall that the dot product of 2 vectors can be written as:
$$x^T y = ||x||\cdot ||y||\cos(\theta)$$
By rearranging for $\cos(\theta)$ we obtain the cosine similarity:
$$\cos (\theta) = \frac{x^Ty}{||x||\cdot ||y||}$$
We can see that this clearly works as a metric for similarity, vectors pointing in almost the same direction give us a cosine value of almost 1, whereas very dissimilar vectors ($180\deg$) have a value of -1. Sometimes, instead of the cosine similarity, people may use the cosine distance, which is defined as $\text{Cosine Distance} = 1-\cos(\theta)$.
# Equivalence
Suppose we don't care about the score itself but rather only the ranking. Assuming that vectors are L2 Normalized, then it is equivalent to use either the Euclidean distance or the Cosine distance. In fact, under these conditions we have: 
$$\text{Euclidean Distance} = 2\cdot \text{Cosine Distance}$$
