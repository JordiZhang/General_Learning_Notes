The functions we are convolving are named the input and the kernel, where the kernel is the function we are using to blur the input function. We have 3 main types of convolution:
Input is blue, dark blue is the kernel and green is the output.
# Valid Convolution
![[valid_conv.png]]
$$
\text{Output length}=\text{Input}-\text{Kernel}+1
$$
This convolution always shrinks the input.
# Full Convolution
![[full_conv.png]]$$
\text{Output length}=\text{Input}+\text{Kernel}-1
$$
This convolution adds padding to the input to allow every non zero convolution.
# Same Convolution
![[same_conv.png]]
This convolution adds just the right amount of padding such that the output is the same length as the input. In particular:
$$
\text{Padding}=\frac{\text{Kernel-1}}{2}
$$
When the kernel is an even size, the padding is not an integer. Then on one side, we round the padding up, while on the opposite side, we round down. However, we rarely utilize even kernels in practice.
