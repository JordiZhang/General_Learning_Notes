TextRank is a method used for text summarization. It builds directly on top of the simpler vector based model detailed in [[1. Common Applications of NLP]]. We copy it here for convenience.
- Split document into sentences
	- Tokenize sentences uses NLTK
	- Build TF-IDF matrix treating each sentence as a document
- Score each sentence
	- Easiest way is to assign the score as the average of the non zero TF-IDF values
- Rank sentences by scores
	- Top N words
	- Top % of words
	- Sentences with score better than threshold (maybe average score or a scaled average score)
- Summary = Top scoring sentences
The main difference is in the way we score sentences, everything else remains the same
# Algorithm
TextRank is based on PageRank, Google's SOTA search ranking from 20+ years ago that made Google what it is today. In a search engine, we would like to compute a score for every website and then rank them accordingly (search). Very similar idea as the TF-IDF summarizer we discussed. The idea behind PageRank is essentially to perform a random walk on every single website and links on the internet. Then after an infinite amount of time the probability of landing on any page is constant and thus we can rank them according to this probability. 

TextRank essentially is just treating documents as the internet and applying PageRank. To do so, we treat sentences as websites. We can also have a similar analogy for the number of links for each website. Recall that we have the TF-IDF vectors of each sentence, then we can use the cosine similarity between TF-IDF vectors as a proxy of the 'number of links' from one sentence to another. Important thing to note is that even though the cosine similarity is symmetric, the probability of the random walk isn't. An authoritative sentence that is linked to a lot of less important ones will have a more spread out probability distribution whereas a non-important sentence linked to an authoritative one only, will have a large probability assigned to that. So essentially, the number of links acts more like a weight. Eventually, the probability distribution converges to a fixed distribution.

A random walk is basically just a first order Markov Chain. The probability of the next state depends only on the current state, and so we have a state transition matrix $A$ as is usual with $M$ total number of states (sentences/websites). Instead of having an initial state distribution, we have just a general state distribution a there is no 'initial' state. Note that previously we had $p(s_{t}|s_{t-1})$, now we have shifted the $t$, but it is equivalent.
$$A_{ij}=p(s_{t+1}|s_t)$$
$$p(s_t)=[p(s_t=1)\quad p(s_t=2\quad ...\quad p(s_t=M))]$$
Note that $p(s_t)$ is by convention a row vector although we normally use column vectors to represent vectors for the rest of the notes. Then the next state distribution is:
$$p(s_{t+1})=p(s_t)A$$
Recall that we would like the distribution at $t=\infty$, to obtain the limiting distribution
$$p(s_\infty)=p(s_0)AAA...=\lim_{t\rightarrow \infty}p(s_0)A^t$$
There is no guarantee that this converges, is unique or that it exists at all. However, if it does exist, it has some nice properties we can use.
$$p(s_\infty)=p(s_\infty)A$$
It should be obvious that the above is true and we note this is just the eigenvalue equation with eigenvalue 1, thus solving it would give us the distribution. There is an important distinction however and that is stationary distributions.
$$p(s_*)=p(s_*)A$$
The stationary distribution is the distribution that remains unchanged by the transformation of matrix $A$. There is nothing that tells us that these two are equivalent from this and they are not necessarily the same.

> [!thm|*] Perron-Frobenius
> If $A$ is a Markov Matrix (rows sum to $1$) and we can travel from any state to any other state with a non-zero positive probability, then $A$ has an eigenvalue of $1$ and the limiting distribution is the same as the stationary distribution and it is unique.

Consider a general PageRank transition matrix $G$ , there will be a lot of zero transition probabilities and so it won't satisfy the requirements of the Perron-Frobenius theorem. So, to deal with this we smooth out the probabilities using a sort of add-epsilon smoothing. We define a uniform matrix $U$ which contains $1/M$ everywhere. Then we take a convex combination of the two matrices as our smoothed transition matrix.
$$A = \alpha U + (1-\alpha)G$$

For TextRank have TF-IDF vectors for each sentence, then we can compute the cosine similarity (there are other ways too) between each pair of sentences and construct the transition matrix. Although the cosine similarity can give negative similarities, this won't be the case here as TF-IDF vectors are constructed to only have positive values, so their inner product will always be positive. To ensure it is a Markov Matrix, we divide each row by the sum of the similarities of said row, so each row sums to $1$. In the same manner, there can still be similarities which are zero, so we smooth the matrix.
