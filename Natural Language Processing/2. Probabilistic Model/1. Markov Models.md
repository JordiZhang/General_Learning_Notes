# Markov Property
--- 
Markov Models are is a stochastic method to model sequences. To do so it attempts to predict the next state in the sequence based on the current sequence of states. In particular, Markov models follow the Markov Property, which is that the probability of the next state is only dependent on the current state, not on the states that happened before it.
$$p(x_t|x_{t-1}, x_{t-2},...) = p(x_t|x_{t-1})$$
This property is also sometimes called the Markov Assumption. The reason for this is that often times we will assume that the Markov Property holds even when it is clear it doesn't. For example, language is a clear example of when the Markov Property doesn't hold, however, we will see that it is still useful in this case and in many others.
# The Markov Model
--- 
Earlier we used $x$ to denote a state, though this usage was mostly due to convention in probability theory. We will instead use $s$ to denote a state, so that $s(t) = s_t$ is the state at time $t$. We will consider time to be discrete and so only integer times. Further, we denote the states $1,2,...,M$ where $M$ is the total number of possible states. As is usual, $i$ or $j$ will be used as indices.

Since we have $M$ number of possible states, we have $M$ number of corresponding probability for each state. These probabilities form part of the state distribution. Recall that Markov Models are used to model sequences, so we define the transition probability following the Markov Property.
$$p(s_t = j| s_{t-1}=i)$$
$i$ and $j$ can take any value between $1$ and $M$, so in total we have $M^2$ transition probabilities. This is reminiscent of matrix notation, so we can define the state transition matrix where:
$$A_{ij} = p(s_t = j| s_{t-1}=i)\qquad \forall i = 1,...,M\qquad j = 1,...,M$$
The convention is that the first index refers to the previous (perhaps more appropriate as the current) state and the second index refers to the next state. In a general sense, the matrix $A_{ij}$ could be time dependent, however in the Markov model, we generally assume time homogeneity. 

The matrix $A_{ij}$ defines the transition probabilities, but what about the first state in a sequence? The matrix tells us nothing about this, so we define an initial state distribution. Note that this is a vector of size $M$.
$$\pi_i = p(s_1=i)$$
## Probability of a Sequence
In general, the probability of a sequence can be found using the chain rule of probabilities.
$$p(s_1, s_2,...,s_t) = p(s_1)p(s_2|s_1)p(s_3|s_1, s_2)...$$
The Markov property simplifies this:
$$p(s_1, s_2,...,s_t) = p(s_1)\prod_{t=2}^Tp(s_t|s_{t-1})$$
Now replacing with $A$ and $\pi$:
$$p(s_1, s_2,...,s_t) = \pi_{s_1}\prod_{t=2}^T A_{s_{t-1},s_t}$$
## Estimating $A$ and $\pi$ 
$$\hat{\pi}_i = \frac{\text{Count}(s_1 = i)}{N}$$
Where $N$ is the total number of sequences.
$$\hat{A}_{ij} = \frac{\text{Count}(i\rightarrow j)}{\text{Count}(i)}$$
So the number of times we see the transition $i\rightarrow j$ divided by the number of times we see the state $i$.
# Probability Smoothing and Log-Probabilities
---
We have already seen how to estimate $A$ and $\pi$ using the maximum likelihood estimators. However, these estimators have some inherent problems with them. For instance, what if one of the transition probabilities is 0? Then by our definition the whole probability is 0, the model then predicts that certain sequences are impossible simply because they were not part of the training dataset, but clearly this shouldn't be the case, we could consider this to be a form of overfitting.
## Add-One Smoothing
One solution to this problem is Add-One Smoothing. We give a small probability to every possible transition so there are no zero transition probabilities, by adding one 'fake' count to each of the transition probabilities.
$$\hat{A}_{ij} = \frac{\text{Count}(i\rightarrow j)+1}{\text{Count}(i)+M}$$
There are $M$ possible transitions for a given $i$ so we also need to add $M$ in the denominator to properly normalize. Doing the same on $\pi$ gives us:
$$\hat{\pi}_i = \frac{\text{Count}(s_1 = i)+1}{N+M}$$
## Add-Epsilon Smoothing
This is identical to Add-One Smoothing but instead we add a user chosen value for Epsilon.
$$\hat{A}_{ij} = \frac{\text{Count}(i\rightarrow j)+\epsilon}{\text{Count}(i)+\epsilon M}$$
$$\hat{\pi}_i = \frac{\text{Count}(s_1 = i)+\epsilon}{N+\epsilon M}$$
Epsilon thus controls how much smoothing we want to introduce in the probability distribution.
## Log-Probabilities
Consider our definition of the probability of a sequence. We have what is just a large product of many probabilities. However, we wish to utilize Markov Models in the context of language, where it we have tons of different words and it is not uncommon to have vocabulary sizes in the tens of thousands. Due to this, all of our probabilities will be very minuscule so our definition of the probability of a sequence is practically always going to give us a tiny almost zero value. Computers do not have infinite precision so after some point it will just round the values to 0.

The solution is to work instead with Log-Probabilities. Our goal in most cases is to compare sequences with each other, so we do not actually care about the actual probability, only whether one is more or less likely that the other.
$$\log(p(s_1, s_2, ...,s_t)) = \log \pi_{s_1}\sum_{t=2}^T \log A_{s_{t-1}, s_t}$$
