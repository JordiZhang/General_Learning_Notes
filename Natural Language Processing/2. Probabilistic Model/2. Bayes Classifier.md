A text classifier is simply a model that takes as input a string of text and then outputs a prediction on what category this text might belong to. To do so, we train a Markov Model for each class. Each model gives us the probability of the given sequence given the class it was trained on. Then we can classify based on:
$$k^*= argmax_k p(class = k|s)$$
Using Bayes' Rule and some simplification steps (ignore constants and take log) we obtain the Maximum A Posteriori Estimator:
$$k^*= argmax_k \log p(s|class = k)+\log p(class=k)$$
If the prior is uniform, then we have:
$$k^*= argmax_k \log p(s|class = k)$$
