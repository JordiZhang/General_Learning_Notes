Neural networks, as the name implies, are composed of a network of interlinked neurons.
![[2-layer DNN.png]]
We have an input layer that passes each of the input features to every subsequent layer. Each of the neurons in the hidden layer are first applying a linear transformation of the form $w^Tx+w_{0}$, and subsequently a non-linear one via an activation function. This processed is repeated for every neuron in a layer and then the outputs of those neurons become the inputs for the new layer. We repeat this for all the hidden layers and then do a final iteration to give us the output of the neural network.
# Activation Functions
What makes a neural network powerful is its non-linearity, which is introduced thanks to the activation functions denoted as $a(x)$. There are many activation functions but some of the more popularly used ones and their uses are listed below:
- Sigmoid, used for classification with 2 classes
$$
\sigma (x)=\frac{1}{1+e^{-x}}
$$
- Softmax, generalization of sigmoid, used for multiclass classification
$$
\text{softmax}(x)_k=\frac{\exp(x_k)}{\sum_{j=1}^K \exp(x_j)} \qquad \text{for }k=1,2,...,K
$$
- tanh, useful due to giving 0-centered outputs, it is a scaled and shifted form of the sigmoid
$$
\tanh (x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}=\frac{2}{1+e^{-2 x}}-1=2 \times \sigma(2 x)-1
$$
- ReLU (Rectified Linear Unit), most common one as it is efficient and fast
$$
\text{ReLU}(x)=\text{max}(0,x)
$$
In practice, we choose an activation function for the output depending on the goal of the mode, for example, sigmoid for classification and identity (no activation) for regression. For the hidden layers we also have some considerations. 

First we take a look at the sigmoid function, it has a S shape and goes from $0$ to $1$. The sigmoid suffers from vanishing gradients, where if the input is too far from 0, the output is in an almost flat region of the function. To solve this we tend to standardize the data so that the inputs are within the non-flat area of the curve. However, we have another issue. When we pass in the input $0$, the sigmoid function returns $0.5$, so although the data is perfectly in the center of its distribution, it returns an offset value that can add up with more layers. 

To rectify this, $\text{tanh}$ is used. With this function we no longer have offset values while keeping the shape of the sigmoid. In general the $\text{tanh}$ function is overall better to use, but there are times that the sigmoid is necessary. 

Finally we have the ReLU function. It has an undefined gradient at $0$, however this in practice does not matter as it is unlikely data is exactly $0$, so we can just define the gradient as either $1$ or $0$. ReLU is particularly popular due to the fact that it has a much more efficient implementation as other activation functions and thus shortens training times. Decision boundaries of models trained with ReLU tend to be much more jagged which leads to the idea that ReLU allows for more flexibility than other activation functions. There are some fundamental problems with ReLU though. For one, the function still has a flat region with a $0$ gradient. This is a known problem and leads to 'dead neurons', which are neurons whose output is $0$ and thus weights depending on this neuron can never learn from it. One 'solution' to this is simply to increase the number of hidden neurons and pray. Due to the better efficiency of ReLU, this rudimentary solution often outperforms other activation functions. Another option is instead to use the leaky ReLU, which adds a small negative gradient to the negative side of ReLU. It could however make the performance worse, but that doesn't mean it is a worse activation.
