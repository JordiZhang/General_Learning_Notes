TF-IDF stands for Term Frequency - Inverse Document Frequency. Earlier we stated that the reason we omit stopwords is that these are words present in basically every document. However, the question then becomes how do we choose a appropriate set of stopwords? For example if we are trying to classify different fields of physics in a journal, almost all of them will have the words' Energy' or perhaps some other physical concept. The purpose of TF-IDF is thus to automatically determine which words are important and which aren't, and therefore help us select the appropriate stopwords to use. The idea behind TF-IDF is to scale down word counts based on how often the words appear in other documents.
# Basic Formulation
$$tfidf(t,d) = tf(t, d) \times idf(t)$$
Where $t$ is the term and $d$ is the document in question. In the most basic formulation we have the following term frequency and inverse document frequency functions:
$$tf(t,d) = \text{Count}(t) \text{ in document d} = \text{Count}(t,d)$$
$$idf(t) = log\left(\frac{N}{N(t)}\right)$$
Where $N$ is the total number of documents and $N(t)$ is the number of documents where the term appears in. The logarithm in this function is very important as it ensures we have sensible results. For example say we have a million documents but for a given term, only 1 document contains the term. Without the logarithm, this $idf$ term would equal a million, but by taking the logarithm its only 13.8. There are also other reasons for this related to information theory but we won't go over it.
# TF Variations
- Binary Representation
$$tf(t,d) = \begin{cases}
1 & \text{if term present in document d}\\
0  & \text{otherwise}
\end{cases}$$
- Normalized Count, divide the count of the terms by sum of counts for each term. If we are working with word tokenization, this would be the wordcount in the document. So instead of count, it is now proportion of a specific term.
$$tf(t,d) = \frac{\text{Count}(t,d)}{\sum_{t'\in terms(d)}\text{Count}(t',d)}$$
- Logarithmic, helps reduce influence of extreme values, similar to IDF logic.
$$tf(t,d) = log(1+\text{Count}(t,d))$$
# IDF Variations
- Smooth IDF, prevents an $idf$ value of 0
$$idf(t) = log\left(\frac{N}{N(t)+1}\right)+1$$
- IDF Max, instead of using the term count for all documents, we use the largest term count for any term in that specific document. Note that this means there is an extra argument in the $idf$ function.
$$idf(t,d) = log\left(\frac{\max_{t'\in terms(d)} N(t')}{N(t)}\right)$$
- Probabilistic IDF, aka logit
$$idf(t) = log\left(\frac{N-N(t)}{N(t)}\right)$$
# Normalizing TF-IDF
Finally we can also normalize the resulting TF-IDF vectors in the usual manner, divide the TF-IDF vector by its corresponding L2 or L1 norm. When done using L2 norm we recover the equivalence of Euclidean and Cosine distances.
