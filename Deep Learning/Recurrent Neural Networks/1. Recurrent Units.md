Recurrent neural networks are a type of neural network architecture primarily used for pattern recognition in sequence data. While ANNs simply pass the information forward, an RNN cycles and transmits information back into itself. This extends the ANN model by allowing it to take into account previous inputs $X_{t-1}$.
![[RNN.png]]
We use different notation here than the one in the neural networks section. It should however be pretty self explanatory. The weights matrix $W_{xh}$ corresponds to the weights between layer $x$ and $h$, thus $W_{hh}$ is the weights for passing information between layer $h$ and itself.

We modify the hidden layer as so:
$$
\begin{align}
h=\sigma(W^T_{h}x+b_{h})&\Rightarrow h_{t}=\sigma_{h}(W_{xh}^Tx_{t}+W_{hh}^Th_{t-1}+b_{h}) \\
y=\sigma(W_{o}^Th+b_{o})&\Rightarrow y_{t}=\sigma_{o}(W_{ho}^Th_{t}+b_{o})
\end{align}
$$
What we have shown above is a recurrent layer built from recurrent units or also known as an Elman unit. These are the recurrent version of a neuron and are stacked in the same manner. Interestingly, RNNs are commonly built with only a single layer of recurrent units, this is partly due to the added complexity of the temporal aspects of RNNs. Therefore, adding more recurrent layers increases complexity immensely and is not a common practice, though there is nothing forbidding it. This also means that layer-based gradient problems are not an issue, however we will see it instead has a different issue due to its temporal aspects.
# Vanishing Gradients
Lets consider backpropagation for the RNN. For simplicity, we only consider a single layer of recurrent units and using identity mappings as activations. Notation differs a bit from the neural networks section as the case considered is simpler (1 layer) than the general one (L layers) we derived for neural networks.
$$
L=\sum_{t=1}^T l_{t}(y_{t})
$$
Then using chain rule we obtain:
$$
\begin{align}
\frac{ \partial L }{ \partial W_{ho} }&=\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }  \frac{ \partial y_{t} }{ \partial \sigma_{o} } \frac{ \partial \sigma_{o} }{ \partial W_{ho} }  \\
&= \sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }  \sigma_{o}' h_{t}
\end{align}
$$
No issue for now, same as standard backpropagation. Now for the other two weight matrices.
$$
\frac{ \partial L }{ \partial W_{hh} }=\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }  \frac{ \partial y_{t} }{ \partial \sigma_{o} } \frac{ \partial \sigma_{o} }{ \partial h_{t} } \frac{ \partial h_{t} }{ \partial \sigma_{h} } \frac{ \partial \sigma_{h} }{ \partial W_{hh} }  
$$
However, we have $h_{t} = h_{t}(x_{1},\dots, x_{t}, W_{xh};h_{1},\dots, h_{t-1}, W_{hh})$. So the last two partial derivatives are incomplete:
$$
\begin{align}
\frac{ \partial L }{ \partial W_{hh} }&=\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }  \frac{ \partial y_{t} }{ \partial \sigma_{o} } \frac{ \partial \sigma_{o} }{ \partial h_{t} } \sum_{k=1}^t \frac{ \partial h_{t} }{ \partial h_{k} } \frac{ \partial h_{k} }{ \partial W_{hh} }   \\
&=\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }  \frac{ \partial y_{t} }{ \partial \sigma_{o} }  W_{ho} \sum_{k=1}^t \frac{ \partial h_{t} }{ \partial h_{k} }   \frac{ \partial h_{k} }{ \partial \sigma_{hk} } \frac{ \partial \sigma_{hk} }{ \partial W_{hh} }   \\
&=\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }    W_{ho} \sum_{k=1}^t \frac{ \partial h_{t} }{ \partial h_{k} }    h_{k-1} \\
&=\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }    W_{ho} \sum_{k=1}^t (W_{hh}^T) ^{t-k}  h_{k-1}
\end{align}
$$
Doing the same calculation for $W_{xh}$, we obtain:
$$
\frac{ \partial L }{ \partial W_{xh} } =\sum_{t=1}^T \frac{ \partial l_{t} }{ \partial y_{t} }    W_{ho} \sum_{k=1}^t (W_{hh}^T) ^{t-k}  x_{t} 
$$
From these two, we can see that the gradient involves a sum of powers of $W_{hh}$ which in turn leads to exploding gradient due to the temporal aspect of RNNs. Therefore, the RNN cannot learn from inputs that are too far back in the sequence. Now if we consider multiple recurrent layers, we have the same issue of vanishing and exploding gradients as we had with the feedforward neural network.
