Instead of utilizing CF or MF algorithms, we can also make use of neural networks to predict unseen ratings. We have seen that [[Embeddings]] can be used to characterize a user/item by converting them into a feature vector. Neural networks work by taking in input characterizing data to output predictions and these embeddings can be used just for that. To do so all we have to do is use the embeddings as our inputs. 
![[recommender_neural_network.png]]
The resulting model performs about as well as our Matrix Factorization algorithm, which may be surprising as MF is linear while NNs are not. 
# Residual Learning
We can extend our model further. This is inspired by methodology used in computer vision. The main idea behind residual learning is that all models attempt to learn features from the input data, but different models might learn different things. Instead of using the neural network to predict the true rating, we can use it to instead predict the error of the matrix factorization model.
$$\hat{r} = MF(x)+ANN(x)$$
$$ANN(x) = \hat{r} - MF(x)$$
![[residual_learning.png]]
Matrix factorization already gives us a good prediction of the rating based only on the linear patterns of the data. The neural network will supplement the MF algorithm by identifying the non linear patterns to predict the error and thus add it to the MF prediction to obtain a better one.

Note that this architecture is extremely similar to the one described on the paper for [Neural Collaborative Filtering](https://arxiv.org/pdf/1708.05031). The only difference is they concatenate the results from the MF and ANN instead of adding.
