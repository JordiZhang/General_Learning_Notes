The Markov assumption we have seen earlier states that the next state depends only on the current one. In particular this is called first order Markov. In fact we can use higher orders of the Markov property and thus have more accurate results. For example second order Markov would mean that the next state depends on the last two states instead of only one.
# New Transition Tensor
Clearly we now have a different transition matrix. Since each probability depends on 2 previous states, the transition matrix is now a 3D tensor. 
$$A_{ijk} = p(s_t = k| s_{t-1}=j, s_{t-2}=i)$$
$$\hat{A}_{ijk}=\frac{\text{Count}(i\rightarrow j \rightarrow k)}{\text{Count}(i\rightarrow j)}$$
Before we had a matrix of size $M^2$, now we have a tensor of size $M^3$. Each additional order increases the size of the transition tensor, so increasingly higher orders gives us larger and larger transition tensors, which is computationally unfeasible. Furthermore, if we consider higher orders, we also require much more data to obtain good results as otherwise we won't have enough occurrences of the different possible transitions to accurately represent language. We denote the order as $A^{(1)}, A^{(2)}$.

The initial state distribution $\pi$ is completely unchanged as regardless of the Markov order in use, $\pi$ is still a one dimensional vector. When using the new model, we require both first and second order transition tensors. The first word is generated from the initial state distribution, the second is generated from the first order transition matrix and then words after are generated using the second order transition tensor. Higher orders follow the same pattern and methodology.
