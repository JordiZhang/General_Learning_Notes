# Motivation

Standard recurrent neural networks (RNNs) struggle to learn long-term dependencies because of the **vanishing gradient problem**. During backpropagation through time, gradients can shrink as they propagate through many time steps, making it difficult for the network to learn how earlier inputs influence later outputs.

**Long Short-Term Memory (LSTM)** networks were introduced to address this limitation. They extend RNNs with a dedicated memory mechanism, called the cell state, and three gates that control how information is retained, added, and exposed over time. This allows important information and gradients to propagate across longer sequences.

# Architecture
LSTM layers are made out of 4 components, the 3 gates and the cell state.
![[LSTM.png]]
The cell state $C$, represents the long term memory of the network, while the hidden states can be considered the short term part of the memory, hence LSTM.

The first part of the architecture is the **forget gate**, it determines how much of the information from the cell state should be forgotten for the next time step. Weights close to 1 thus indicate important information that should be remembered for longer, and so weights close to 0 indicate the opposite.

The second stage involves $\widetilde{C}_{t}$, which generates a new **potential candidate memory**, then the **input gate** determines how much of the candidate memory should be remembered by the cell state. The result is then added onto the "forgotten" cell state to obtain the new cell state at time $t$.

At this stage, all that is left is to update the short term memory. The cell state is passed through a $\tanh$ activation which becomes the new candidate $\tilde{h}_{t}$. Then the output gate determines how much of the new candidate short term memory should be remembered, and thus we obtain the updated hidden state. This is also the output of the LSTM layer, hence the output gate, and it is what we use to make any predictions.

The equations for these gates should be relatively obvious. If that is not the case, look at Recurrent units and possibly neural networks as a reminder. Note that the inputs and hidden states are concatenated before passed through the gates.
