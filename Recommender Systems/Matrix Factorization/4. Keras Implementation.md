To implement Matrix Factorization using Keras we utilize [[Embeddings]] layers. Suppose we have $N$ words and $K$ embedding dimensions, then our embedding of the words is a matrix of size $(N\times K)$. We can treat users and movies in a similar manner by embedding their relationships and information into matrices. Thus we have $W(N\times K)$ and $U(M\times K)$ which is the same as for Matrix Factorization. We setup the matrix factorization as a Keras model and instead of using alternating least squares, we use gradient descent as is usual for neural networks. 
```python
# embedding layers
emb_u = Embedding(N, K)
emb_m = Embedding(M, K)

# inputs
u = Input()
m = Input()

# embedded inputs
eu = emb_u(u)
em = emb_m(m)

# prediction
r = dot(eu, em)
```
# Adding Biases
This is simple to do and once again we utilize embedding layers. User bias and movie bias are just one dimensional arrays, so we can implement them as more embedding layers.
```python
# biases
bias_u = Embedding(N, 1)
bias_m = Embedding(M, 1)

# embeds
bu = bias_u(u)
bm = bias_m(m)

# prediction with biases
r = add(r, bu, bm)
```
As for the global mean, adding it is not straightforward, so instead we make our target for the Keras model to be the actual rating - global mean.
# Note on Keras
Keras embedding layers are designed for natural language processing, in which case sequences of words matter. As such, the layers are designed to take in inputs of size T, and then outputs an array of size T. As such the resulting output of `emb_u(u)` is not size $(N \times K)$, but rather $(N\times 1 \times K)$.
