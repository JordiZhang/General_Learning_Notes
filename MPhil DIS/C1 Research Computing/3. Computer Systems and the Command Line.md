# Von Neumann Model
In the Von Neumann model, a computer has a processor (a control unit, an arithmetic-logic unit and registers), one memory holding both the program and its data, and input/output devices, connected by a bus: a shared set of lines carrying addresses (which location), data (the bits) and
control signals (such as read or write).

# Operating System
An operating system manages hardware and provides services to programs. The kernel is its privileged core. It schedules processes, manages virtual memory and filesystems, and controls access to devices and the network. Programs request these services through system calls. Utilities, libraries and graphical interfaces are also part of an operating system.

# Shell
A shell is a program that reads a command line, finds the named program, and starts it with the specified arguments. It then prints a prompt and waits for another command. zsh is the default on macOS; bash is common on Linux and is used on CSD3. Many command examples work in both shells.
- A command line contains a program name, options and arguments. Many short options use one dash and a letter (`-l`); long options usually use two dashes and a word (`--help`)
- The program is looked up along PATH, its output is shown on the terminal unless redirected
- A terminal application (Terminal, iTerm or the VS Code terminal panel) provides the window and keyboard input. The shell is a separate program running inside it; the shell reads and interprets each command.
## Startup Files
Bash startup files commonly include `~/.bashrc` and `~/.bash_profile`. Zsh startup files commonly include `~/.zshrc` and `~/.zprofile`. They can store settings such as PATH, the prompt and aliases; for example, alias `ll=’ls -l’` defines an alias named `ll`. The home directory prefix `~/` means the file is in the user’s home directory.

# File Systems
A file system organises stored data into named files and directories. The operating system presents the directories as a tree rooted at /. The Filesystem Hierarchy Standard describes common Linux directory roles. macOS shares many of these names and has additional directories.

## File System Formats
A file system format specifies how file names, data and metadata are stored on a volume. Formats differ in case sensitivity, supported file sizes and permission metadata.
