In essence, this is an application of Matrix Factorization that was devised for recommender systems, but applied to the document-word matrix (count vectorized documents). The difference being, the matrices involved only contain non-negative values. This makes sense as documents are modelled as a mixture of topics and we can't have a negative amount of a topic, and topics contain non-negative amounts of words. Non-negativity is ensured via the training procedure. Then each document is a mixture of the $K$ latent topics. Then the factorized matrices correspond to a matrix representing the mixture of topics for each document, and a matrix representing the mixture of words for each topic.

Non-negative matrix factorization using Kullback-Leibler divergence as the loss and using multiplicative update is essentially the same algorithm as using Latent Semantic Indexing. However, note that in general matrix factorization and SVD are not the same algorithm, MF is used for sparse matrices whereas SVD is not even compatible with non complete matrices.
