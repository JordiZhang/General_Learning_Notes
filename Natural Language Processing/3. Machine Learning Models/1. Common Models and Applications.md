Remember that the type of data you use doesn't really matter, what matters is what sort of problem you may have. In this section, for example, spam detection and binary sentiment analysis are exactly the same type, supervised machine learning -> classifier. So the methods discussed are clearly interchangeable. Also this section only deals in non deep learning methods and techniques.
# Spam Detection
The goal is to detect spam emails out of the normal ones. It is a supervised machine learning problem and is commonly approached using a [[Naive Bayes Classifier]]. One way of doing so might be to first tokenize all the data and then estimate the probability distributions using maximum likelihood estimation. Then apply Bayes' Theorem and obtain posteriors which would indicate which class the data belongs to.
# Sentiment Analysis
The goal is to analyse text and classify the overall sentiment of the text. Typically this is a classification task with binary classes, though we may also have 3, 5 or even more classes. However, it is also appropriate to treat as a regression task, perhaps 0 is neutral, 1 is absolute positive and -1 is absolute negative. In fact, recommender systems are an example of where sentiment is treated as a regression task. With cases where we are interested in many classes it tends to be more appropriate to treat it as a regression problem as the classes are in fact not independent and are ordered. This could be done using a logistic regression.
# Text Summarization
It is as the name implies. There are 2 types of summarization, extractive and abstractive summarization. Extractive summaries are summaries that consist of text taken from the original document. Meanwhile abstractive ones are summaries that can contain novel sequences of text not necessarily taken from the input text. Extractive summaries are easier to generate whereas abstractive ones are hard. We only look at extractive ones here as abstractive ones are more suited to deep learning models. 
## Using Vectors
- Split document into sentences
	- Tokenize sentences uses NLTK
	- Build TF-IDF matrix treating each sentence as a document
- Score each sentence
	- Easiest way is to assign the score as the average of the non zero TF-IDF values
- Rank sentences by scores
- Summary = Top scoring sentences
