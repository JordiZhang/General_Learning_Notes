In neural networks, the loss function is in general does not have a closed form solution for the minima, so we utilize gradient descent. Consider an arbitrary neural network, then we define the following variables:
$$
\begin{align}
L&=L(a_{i}^{(L)}) \\
a_{i}^{(l)} &= a_{i}^{(l)}(z_{i}^{(l)}) \\
z_{i}^{(l)} &= \sum_{j=1} (W_{ij}^{(l)}a_j^{(l-1)}) + b_{i}^{(l)}
\end{align}
$$
The superscript denotes the layer of the neural network, where higher values of $l$ are deeper in the network with a maximum layer of $L$ which is the output layer. $z_i^{(l)}$ represents the linear transformation at each neuron of layer $l$ using the weights $W_{ij}^{(l)}$ and bias $b_{i}^{(l)}$. Then $a_i^{(l)}$ represents the activation function and is a function of the linear transformations $z_i^{(l)}$. $W_{ij}$ is the weight for neuron i given input j from the previous layer. The indices are the neuron's index at each layer. We wish to find the gradient with respect to each of the weights so we can use gradient descent to update them. To do so we work backwards starting from the loss and the output layer:
$$
\begin{align}
\frac{ \partial L }{ \partial W_{ij}^{(L)} } &= \frac{ \partial L }{ \partial a_{i}^{(L)} } \frac{ \partial a_{i}^{(L)} }{ \partial z_{i}^{(L)} }\frac{ \partial z_{i}^{(L)} }{ \partial W_{ij}^{(L)} }    \\
&= \frac{ \partial L }{ \partial a_{i}^{(L)} } \frac{ \partial a_{i}^{(L)} }{ \partial z_{i}^{(L)} }a_{j}^{(L-1)}
\end{align}
$$
Then lets consider the next layer:
$$
\frac{ \partial L }{ \partial W_{jk}^{(L-1)} }= \sum_{i=1} \frac{ \partial L }{ \partial a_{i}^{(L)} } \frac{ \partial a_{i}^{(L)} }{ \partial z_{i}^{(L)} }  \frac{ \partial z_{i}^{(L)} }{ \partial a_{j}^{(L-1)} } \frac{ \partial a_{j}^{(L-1)} }{ \partial z_{j}^{(L-1)} } \frac{ \partial z_{j}^{(L-1)} }{ \partial W_{{jk}}^{(L-1)} } 
$$
The above expression can be generalized for any $l$ as it is iteratively defined and is the exact same expression every time. Then we define the error (conventionally named):
$$
\delta^{(l)}_{i} = \frac{ \partial L }{ \partial z_{i}^{(l)} }=  \frac{ \partial L }{ \partial a_{i}^{(l)} } \frac{ \partial a_{i}^{(l)} }{ \partial z_{i}^{(l)}}
$$
Such that:
$$
\frac{ \partial L }{ \partial W_{ij}^{(L)} }= \delta_{i}^{(L)}\cdot a_{j}^{(L-1)}
$$
$$
\begin{align}
\frac{ \partial L }{ \partial W_{jk}^{(l-1)} }&= \sum_{i=1} \delta_{i}^{(l)}  \frac{ \partial z_{i}^{(l)} }{ \partial a_{j}^{(l-1)} } \frac{ \partial a_{j}^{(l-1)} }{ \partial z_{j}^{(l-1)} } \frac{ \partial z_{j}^{(l-1)} }{ \partial W_{{jk}}^{(l-1)} }  =\delta_{j}^{(l-1)}\cdot a_{k}^{(l-2)}\\
&= \sum_{i=1}\delta_{i}^{(l)}W_{ij}^{(l)} \frac{ \partial a_{j}^{(l-1)} }{ \partial z_{j}^{(l-1)} } a_{k}^{(l-2)} = \delta_{j}^{(l-1)}\cdot a_{k}^{(l-2)} \\ 
\therefore \delta_{j}^{(l-1)}&=\sum_{i=1}\delta_{i}^{(l)}W_{ij}^{(l)} \frac{ \partial a_{j}^{(l-1)} }{ \partial z_{j}^{(l-1)} }
\end{align}
$$
And thus we arrive at backpropagation, at each layer $\delta^{(l)}_{i}$ is calculated and propagated to the previous layer since it is an iterative formula. We will now convert it into a matrix form for computing efficiency. Instead of computing the derivative with respect to each individual weight, we are interested in the derivative with respect to the entire weight matrix for a layer. We have a weights matrix $W^{(l)}$ and the column vectors $\delta^{(l)}$ and $a^{(l)}$, so the matrix form of the gradient:
$$
\frac{ \partial L }{ \partial W^{(l)} }= \delta^{(l)}(a^{(l-1)})^T
$$
Then for the error, in feedforward neural networks the activation function for each neuron in a layer is identical, so the partial derivatives are too. We can thus simplify the sum as a inner product and then an element-wise product with the derivative of the activation:
$$
\delta^{(l-1)}= (W^{(l)})^T\delta^{(l)} \odot \frac{ \partial a^{(l-1)} }{ \partial z^{(l-1)} } 
$$
Then for the gradient with respect to the biases, we go through the same methodology and obtain a very similar expression:
$$
\frac{ \partial L }{ \partial b^{(l)} }= \delta^{(l)} (\mathbb{1})^T 
$$
This derivation assumes a single input vector as can be seen when we consider $a^{(l)}$ to be column vectors. For practical reasons, we may also be interested in the many sample regime. In fact the equations are identical, except that now $\delta^{(l)}$ and $a^{(l)}$ are matrices. One small caveat though, for many samples, we can define the loss as the sum of the individual losses for each sample or as a mean. If using the latter convention (you should), then we must also divide the gradient by the number of samples.
