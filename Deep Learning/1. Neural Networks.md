Neural networks, as the name implies, are composed of a network of interlinked neurons.
![[2-layer DNN.png]]
We have an input layer that passes each of the input features to every subsequent layer. Each of the neurons in the hidden layer are first applying a linear transformation of the form $w^Tx+w_{0}$, and subsequently a non-linear one via an activation function. This processed is repeated for every neuron in a layer and then the outputs of those neurons become the inputs for the new layer. We repeat this for all the hidden layers and then do a final iteration to give us the output of the neural network.
# Activation Functions
What makes a neural network powerful is its non-linearity, which is introduced thanks to the activation functions denoted as $a(x)$. There are many activation functions but some of the more popularly used ones and their uses are listed below:
- Sigmoid, used for classification with 2 classes
$$
\sigma (x)=\frac{1}{1+e^{-x}}
$$
- Softmax, generalization of sigmoid, used for multiclass classification
$$
\text{softmax}(x)_k=\frac{\exp(x_k)}{\sum_{j=1}^K \exp(x_j)} \qquad \text{for }k=1,2,...,K
$$
- tanh, useful due to giving 0-centered outputs, it is a scaled and shifted form of the sigmoid
$$
\tanh (x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}=\frac{2}{1+e^{-2 x}}-1=2 \times \sigma(2 x)-1
$$
- ReLU (Rectified Linear Unit), most common one as it is efficient and fast
$$
\text{ReLU}(x)=\text{max}(0,x)
$$
In practice, we choose an activation function for the output depending on the goal of the mode, for example, sigmoid for classification and identity (no activation) for regression. For the hidden layers we also have some considerations. 

First we take a look at the sigmoid function, it has a S shape and goes from $0$ to $1$. The sigmoid suffers from vanishing gradients, where if the input is too far from 0, the output is in an almost flat region of the function. To solve this we tend to standardize the data so that the inputs are within the non-flat area of the curve. However, we have another issue. When we pass in the input $0$, the sigmoid function returns $0.5$, so although the data is perfectly in the center of its distribution, it returns an offset value that can add up with more layers. 

To rectify this, $\text{tanh}$ is used. With this function we no longer have offset values while keeping the shape of the sigmoid. In general the $\text{tanh}$ function is overall better to use, but there are times that the sigmoid is necessary. 

Finally we have the ReLU function. It has an undefined gradient at $0$, however this in practice does not matter as it is unlikely data is exactly $0$, so we can just define the gradient as either $1$ or $0$. ReLU is particularly popular due to the fact that it has a much more efficient implementation as other activation functions and thus shortens training times. Decision boundaries of models trained with ReLU tend to be much more jagged which leads to the idea that ReLU allows for more flexibility than other activation functions. There are some fundamental problems with ReLU though. For one, the function still has a flat region with a $0$ gradient. This is a known problem and leads to 'dead neurons', which are neurons whose output is $0$ and thus weights depending on this neuron can never learn from it. One 'solution' to this is simply to increase the number of hidden neurons and pray. Due to the better efficiency of ReLU, this rudimentary solution often outperforms other activation functions. Another option is instead to use the leaky ReLU, which adds a small negative gradient to the negative side of ReLU. It could however make the performance worse, but that doesn't mean it is a worse activation.
# Feedforward In Depth
Let each of the inputs be $x_i$ and each of the neuron outputs in the first hidden layer be $z_j$. Consider a neural network with $K$ inputs and $M$ neurons in the single hidden layer fed into a single output neuron. We denote the activation function of the hidden layer as $a_{1}$ and the activation function of the output as $a_2$. Each neuron applies a linear transformation to the input vector and then applies the activation function:
$$z_{j}=a_{1}\left( \sum_{i=1}^K(W_{ji}x_{i})+b_{j} \right)$$
where $W_{ij}$ is the weight corresponding to neuron $i$ and input $j$ and is thus a matrix of size $\text{Neurons in layer} \times \text{Inputs}$.
$$
Z=
\begin{bmatrix}
z_{1}\\
\vdots \\
z_{M}
\end{bmatrix}
=a_{1} \left(
\begin{bmatrix}
\sum_{i=1}^K(W_{1i}x_{i})+b_{1} \\
\vdots \\
\sum_{i=1}^K(W_{Mi}x_{i})+b_{M}
\end{bmatrix}
\right)
=
a_{1}
\left(
\begin{bmatrix}
W_{11} & \cdots & W_{1K} \\
\vdots & \ddots & \vdots \\
W_{M1} & \cdots & W_{MK}
\end{bmatrix}
\begin{bmatrix}
x_{1} \\
\vdots \\
x_{K}
\end{bmatrix}
+
\begin{bmatrix}
b_{1} \\
\vdots \\
b_{M}
\end{bmatrix}
\right)
$$
Simplifying into matrices and vectors we get:
$$
Z=a_{1}(Wx+b)
$$
Now we can calculate the output:
$$
y=a_{2}(Va_{1}(Wx+b)+c)
$$
where $V$ is the weights matrix of the next layer, in our case the output so it really is just a vector in this case.

In this above working, $x$ is a vector and $x_i$ are components of the vector, however in the following section we will see how to generalize this to any number of samples by considering a matrix $X$ consisting of different samples of $x$. So we will change the notation such that $x_i$ denotes a vector representing sample $i$. Then if we have $N$ samples, we have:
$$
Y=
\begin{bmatrix}
y_{1} &
\cdots &
y_{N}
\end{bmatrix}
=
\begin{bmatrix}
a_{2}(Va_{1}(Wx_{1}+b)+c) &
\cdots &
a_{2}(Va_{1}(Wx_{N}+b)+c)
\end{bmatrix}
$$
Then $X =\begin{bmatrix}x_{1} & \cdots & x_{N}\end{bmatrix}$. Note that in implementations, it is usual to use row notation instead, so this would change our expressions.
$$
Y=a_{2}(Va_{1}(WX+b)+c)
$$
Thus we obtain a matrix expression for calculating the output efficiently, this can be extended to any number of layers in the same fashion. One caveat though, $WX$ results in a $M\times N$ matrix while the biases are $M$ length vectors, this is clearly wrong. In theory the biases are also $M\times N$ matrices:
$$
b=\begin{bmatrix}
b&
\cdots &
b
\end{bmatrix}
$$
In practice, NumPy will broadcast them correctly without needing to explicitly construct the bias matrix.

What if we have multiple outputs and we use Softmax as the activation? Then our output is an $K\times N$ matrix. Neurons output probabilities, so in this case, whichever probability is largest, then we classify as that class.
# Backpropagation
In neural networks, the loss function is in general does not have a closed form solution for the minima, so we utilize gradient descent. Consider an arbitrary neural network, then we define the following variables:
$$
\begin{align}
L&=L(a_{i}^{(L)}) \\
a_{i}^{(l)} &= a_{i}^{(l)}(z_{i}^{(l)}) \\
z_{i}^{(l)} &= \sum_{j=1} (W_{ij}^{(l)}a_j^{(l-1)}) + b_{i}^{(l)}
\end{align}
$$
The superscript denotes the layer of the neural network, where higher values of $l$ are deeper in the network with a maximum layer of $L$ which is the output layer. $z_i^{(l)}$ represents the linear transformation at each neuron of layer $l$ using the weights $W_{ij}^{(l)}$ and bias $b_{i}^{(l)}$. Then $a_i^{(l)}$ represents the activation function and is a function of the linear transformations $z_i^{(l)}$. The indices are the neuron's index at each layer. We wish to find the gradient with respect to each of the weights so we can use gradient descent to update them. To do so we work backwards starting from the loss and the output layer:
$$
\begin{align}
\frac{ \partial L }{ \partial W_{ij}^{(L)} } &= \frac{ \partial L }{ \partial a_{i}^{(L)} } \frac{ \partial a_{i}^{(L)} }{ \partial z_{i}^{(L)} }\frac{ \partial z_{i}^{(L)} }{ \partial W_{ij}^{(L)} }    \\
&= \frac{ \partial L }{ \partial a_{i}^{(L)} } \frac{ \partial a_{i}^{(L)} }{ \partial z_{i}^{(L)} }a_{j}^{(L-1)}
\end{align}
$$
Then lets consider the next layer:
$$
\frac{ \partial L }{ \partial W_{jk}^{(L-1)} }= \sum_{i=1} \frac{ \partial L }{ \partial a_{i}^{(L)} } \frac{ \partial a_{i}^{(L)} }{ \partial z_{i}^{(L)} }  \frac{ \partial z_{i}^{(L)} }{ \partial a_{j}^{(L-1)} } \frac{ \partial a_{j}^{(L-1)} }{ \partial z_{j}^{(L-1)} } \frac{ \partial z_{j}^{(L-1)} }{ \partial W_{{jk}}^{(L-1)} } 
$$
The above expression can be generalized for any $l$ as it is iteratively defined and is the exact same expression every time. Then we define the error (conventionally named):
$$
\delta^{(l)}_{i} = \frac{ \partial L }{ \partial z_{i}^{(l)} }=  \frac{ \partial L }{ \partial a_{i}^{(l)} } \frac{ \partial a_{i}^{(l)} }{ \partial z_{i}^{(l)}}
$$
Such that:
$$
\frac{ \partial L }{ \partial W_{ij}^{(L)} }= \delta_{i}^{(L)}\cdot a_{j}^{(L-1)}
$$
$$
\begin{align}
\frac{ \partial L }{ \partial W_{jk}^{(l-1)} }&= \sum_{i=1} \delta_{i}^{(l)}  \frac{ \partial z_{i}^{(l)} }{ \partial a_{j}^{(l-1)} } \frac{ \partial a_{j}^{(l-1)} }{ \partial z_{j}^{(l-1)} } \frac{ \partial z_{j}^{(l-1)} }{ \partial W_{{jk}}^{(l-1)} }  =\delta_{j}^{(l-1)}\cdot a_{k}^{(l-2)}\\
&= \sum_{i=1}\delta_{i}^{(l)}W_{ij}^{(l)} \frac{ \partial a_{j}^{(l-1)} }{ \partial z_{j}^{(l-1)} } a_{k}^{(l-2)} = \delta_{j}^{(l-1)}\cdot a_{k}^{(l-2)} \\ 
\therefore \delta_{j}^{(l-1)}&=\sum_{i=1}\delta_{i}^{(l)}W_{ij}^{(l)} \frac{ \partial a_{j}^{(l-1)} }{ \partial z_{j}^{(l-1)} }
\end{align}
$$
And thus we arrive at backpropagation, at each layer $\delta^{(l)}_{i}$ is calculated and propagated to the previous layer since it is an iterative formula. We will now convert it into a matrix form for computing efficiency. Instead of computing the derivative with respect to each individual weight, we are interested in the derivative with respect to the entire weight matrix for a layer. We have a weights matrix $W^{(l)}$ and the column vectors $\delta^{(l)}$ and $a^{(l)}$, so the matrix form of the gradient:
$$
\frac{ \partial L }{ \partial W^{(l)} }= \delta^{(l)}(a^{(l-1)})^T
$$
Then for the error, in feedforward neural networks the activation function for each neuron in a layer is identical, so the partial derivatives are too. We can thus simplify the sum as a inner product and then an element-wise product with the derivative of the activation:
$$
\delta^{(l-1)}= (W^{(l)})^T\delta^{(l)} \odot \frac{ \partial a^{(l-1)} }{ \partial z^{(l-1)} } 
$$
Then for the gradient with respect to the biases, we go through the same methodology and obtain a very similar expression:
$$
\frac{ \partial L }{ \partial b^{(l)} }= \delta^{(l)} (\mathbb{1})^T 
$$
