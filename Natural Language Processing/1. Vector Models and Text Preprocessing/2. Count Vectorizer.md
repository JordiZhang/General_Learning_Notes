This is the simplest method of vectorizing a document and it consists of simply counting the number of instances a word appears in the document. To do this, we need to know the vocabulary size for the entire corpus, and we assign a unique position in the vector to each word in the vocabulary. Then the vector representation of the document is simply the resulting vector of the counts for each word.

Note however that we have several practical issues with using a model like this. For one there are discrepancies between document sizes. A large and a small document might have the same number of counts for a certain word, but these might mean very different things depending on how large the document is. To solve this we can normalize the vectors. We have 2 ways of doing so
- Normalize using L2 norm, so the norm of the vector is 1
- Divide by the total number of words in the document (this is also the sum of the vector elements), so each vector component represents the rate of appearance of the word in it. This is equivalent to normalizing vectors using L1 norm, so its L1 norm is 1.
